# Ключи, деньги и типовые сбои

Справочник к `/jadlis-voice`. Читается перед шагом «Ключи» и когда что-то не сходится.

## Ключи

| Имя | Зачем | Обязателен | Где завести |
|---|---|---|---|
| `ELEVENLABS_API_KEY` | распознавание речи (`scribe_v2`) и озвучка буфера | да | https://elevenlabs.io |
| `ANTHROPIC_API_KEY` | чистка распознанного текста (`claude-sonnet-5`) | да | https://console.anthropic.com |
| `OPENAI_API_KEY` | резерв чистки (`gpt-5.6-sol`) | нет | https://platform.openai.com |

Хранение — Связка ключей macOS: generic password, service `jadlis`, account = имя ключа.
Тот же стандарт, что у `jadlis-search` (`scripts/secret.sh`). Пишет ключ `scripts/keys.sh set`:
значение читается скрытым вводом с терминала или со stdin, аргументом командной строки — никогда.

`ANTHROPIC_API_KEY` — это ключ **Console**, отдельный платный счёт. Подписка на Claude (Pro, Max)
сюда не подходит: у неё нет ключа, который принял бы Spokenly.

Ключи попадают в файл настроек Spokenly открытым текстом — так устроено само приложение, своего
канала в Связку ключей оно не даёт. Отсюда правило: файл `~/Library/Preferences/app.spokenly.plist`
никуда не пересылать, в репозитории не хранить, агенту читать не давать. Шаблон в `assets/`
хранит на месте ключей плейсхолдеры, а подстановка происходит только на машине человека.

## Деньги

- **Оплата по факту** у всех трёх провайдеров, подписки не нужно; у каждого есть минимальное
  пополнение счёта, без него ключ не заработает.
- **Распознавание** тарифицируется по минутам записи, **чистка** — по числу токенов короткого
  текста. Обе величины на бытовом объёме диктовки маленькие.
- **Точные цены смотри на страницах тарифов провайдеров** — они меняются, и любая цифра здесь
  устареет раньше, чем ты её прочитаешь.
- **Само приложение бесплатное**, когда работает на своих ключах. Подписка Spokenly Pro нужна
  только под их собственные облачные модели — этому контуру она не требуется.

## Модель и настройки, которые ставит шаблон

| Настройка | Значение |
|---|---|
| Модель распознавания | `elevenlabs-api` (`scribe_v2`) |
| Чистка текста | Anthropic → `claude-sonnet-5` |
| Резерв чистки | OpenAI → `gpt-5.6-sol` (убирается, если ключа нет) |
| Режим вставки | `autoInsert` — текст сам встаёт в активное поле |
| Горячая клавиша | правый Command, `activationMode: toggle` |
| Словарь замен | 10 пар, срабатывают до чистки (`beforeAI`) |

## Когда не работает

**Текст не вставляется в поле.** Не выдан Универсальный доступ (Accessibility). Системные
настройки → Конфиденциальность и безопасность → Универсальный доступ → включить Spokenly.
Если Spokenly уже в списке и включён — сними и поставь галочку заново.

**Записи нет вообще.** Не выдан Микрофон, либо выбран не тот вход. Проба покажет
`spokenly_plist=yes`, но диктовка молчит — проверь Системные настройки → Микрофон.

**Импорт настроек не подействовал.** Приложение было открыто. `defaults import` при живом
Spokenly перетирается его собственной записью. Закрой через ⌘Q (не крестиком), проверь
`spokenly_running=no` в пробе и запусти импорт заново.

**Настройки читаются не те.** Домен `app.spokenly` (по бандл-id) ведёт в старый sandbox-контейнер:
приложение вышло из песочницы в 08.2026, и живой файл лежит по пути
`~/Library/Preferences/app.spokenly.plist`. Все инструменты плагина адресуют домен путём к файлу.

**Ошибка провайдера при чистке.** Кончились деньги на счёте Anthropic либо ключ отозван.
Проверь баланс в Console; если стоит ключ OpenAI — Spokenly переключится на резерв сам.

**Откат настроек.** Резервная копия лежит в `~/Archive/spokenly-<дата>.plist`:
`defaults import ~/Library/Preferences/app.spokenly.plist ~/Archive/spokenly-<дата>.plist`.

## Озвучка буфера

**Не слышно ничего, ошибки нет.** Пустой буфер обмена — скрипт молча выходит. Скопируй текст.

**Ничего не происходит по тапу.** Karabiner не получил доступ к вводу (его собственный диалог
в Системных настройках) или правило ушло в другой профиль — проверь `karabiner_rule=yes` в пробе.

**Уведомление «нет плеера play».** Не поставлен sox: `brew install sox`. Скрипт проверяет плеер
и ключ до платного запроса, поэтому денег такая попытка не стоит.

**Уведомление про ключ.** В Связке нет `ELEVENLABS_API_KEY`. Запасной путь — старая запись
service `elevenlabs`, account = имя пользователя; её скрипт тоже читает.

**Лог** — `$TMPDIR/jadlis-speak.log`. Значений ключей в него не попадает.
