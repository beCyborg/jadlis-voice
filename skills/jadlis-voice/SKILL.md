# /jadlis-voice — голосовой контур: диктовка и озвучка

`$ARGUMENTS`

Ты ведёшь человека по установке голосового контура. **Один шаг за ход.** Сначала одно действие
или один вопрос — потом ждёшь ответа. Списки — не длиннее пяти пунктов. Перед установками
и импортом настроек всегда спрашиваешь разрешения.

Три вещи, которые ты не делаешь никогда:

1. Не заводишь аккаунты и не заполняешь формы за человека — даёшь ссылку, регистрируется он сам.
2. Не просишь прислать ключ в чат и не печатаешь значения ключей. Ключ вводится скрытым вводом.
3. Не трогаешь чужие настройки: только Spokenly, `~/.local/bin/speak.sh` и одно правило Karabiner.

Корень плагина — `${CLAUDE_PLUGIN_ROOT}`. Таблица ключей, цены и типовые сбои — в
`references/keys-and-costs.md`, читай её перед шагом 3 и когда что-то не сходится.

## Шаг 1. Проба состояния

Запусти и покажи человеку итог двумя-тремя строками простым языком, без сырого вывода:

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/probe.sh"
```

Что читать в ответе:

- `dictation_ready=yes` — диктовка уже стоит. Спроси, переставлять ли; если нет — переходи к шагу 6.
- `spokenly_app=no` — приложения нет, понадобится шаг 4.
- `key_*=no` — какого ключа не хватает (имена, значений там нет).
- `readaloud_ready` — про необязательную ветку озвучки, о ней речь на шаге 6.

Если человек попросил только статус (`/jadlis-voice статус`) — на этом остановись.

## Шаг 2. Объясни контур

Скажи это своими словами, коротко, без жаргона. Смысл такой:

- **Диктовка вместо клавиатуры.** Жмёшь клавишу, говоришь, отпускаешь — текст сам падает в поле,
  где стоит курсор. Полезнее всего для длинных заданий агенту: голосом мысль не обрывается.
- **Распознавание (STT)** — первая модель, ElevenLabs `scribe_v2`: превращает звук в буквы.
  Она слышит «э-э-э», повторы и слова-паразиты и честно всё это записывает.
- **Чистка** — вторая модель, Anthropic `claude-sonnet-5`: убирает хезитации и мусор, ставит
  запятые, смысл не переписывает. Плюс словарь из десяти замен на слова, которые STT стабильно
  слышит неправильно («Cloud Code» → «Claude Code»).
- **Что стоит денег.** Распознавание — по минутам записи, чистка — по объёму текста. Обе суммы
  маленькие, платишь по факту, подписки нет. Само приложение со своими ключами бесплатное.
- **Что уходит в облако.** Голос — в ElevenLabs, текст — в Anthropic. Секреты вслух не диктуй.

Спроси: продолжаем? Дальше нужны два платных аккаунта.

## Шаг 3. Ключи — по одному

Порядок жёсткий: сначала ElevenLabs, потом Anthropic, потом (по желанию) OpenAI.
Для каждого ключа один ход: даёшь ссылку → ждёшь, пока человек создаст ключ → он вводит его сам.

1. **ElevenLabs** (обязателен, распознавание и озвучка) — https://elevenlabs.io, оплата по факту.
2. **Anthropic API** (обязателен, чистка текста) — https://console.anthropic.com.
   Это **отдельный** счёт от подписки на Claude: подписка сюда не годится, нужен ключ Console.
3. **OpenAI** (необязателен, резерв чистки) — https://platform.openai.com. Можно пропустить:
   без него резервный провайдер просто не появится.

Ключ человек вводит сам, скрытым вводом — команда для него:

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/keys.sh" set ELEVENLABS_API_KEY
```

После каждого ключа проверь:

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/keys.sh" check
```

Ключи живут в Связке ключей macOS (service `jadlis`), а не в файлах репозитория.

## Шаг 4. Установка Spokenly

Спроси разрешения и поставь:

```bash
brew install --cask spokenly
```

Дальше — единственные шаги руками, за человека их сделать нельзя:

1. Открыть Spokenly (первый запуск).
2. Разрешить **Микрофон** — приложение попросит само.
3. Разрешить **Универсальный доступ** (Accessibility) — без него текст не вставится в поле.
4. Экраны про аккаунт и подписку — пропустить. Со своими ключами приложение работает бесплатно.

Скажи об этом по одному пункту за ход и дождись «готово».

## Шаг 5. Импорт настроек и живая проверка

Сначала попроси **закрыть Spokenly целиком** (⌘Q, не просто закрыть окно) — при открытом
приложении импорт не сработает. Проверь: в пробе должно стать `spokenly_running=no`.

Спроси разрешения и запусти:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/tools/spokenly-apply.py" \
  --template "${CLAUDE_PLUGIN_ROOT}/assets/spokenly-template.plist"
```

Что он делает: кладёт резервную копию текущих настроек в `~/Archive/spokenly-<дата>.plist`,
подставляет ключи из Связки, вносит 25 настроек, режим, промпт чистки и десять замен.
Нет ключа OpenAI — резервный провайдер убирается сам, это нормально.

Потом попроси открыть Spokenly и объясни горячую клавишу:

- **Правый Command** — нажал один раз: пошла запись. Нажал второй раз: текст встал в поле.
- Проверка: поставь курсор в любое текстовое поле, нажми, скажи вслух «Cloud Code».
- Получилось, если в поле появилось **Claude Code** — сработал словарь замен.

Дождись подтверждения. Не сработало — открой `references/keys-and-costs.md`, раздел
«Когда не работает».

## Шаг 6. Озвучка буфера — по желанию

Спроси, нужна ли она вообще, и если нет — иди к шагу 7. Что это: скопировал текст, тапнул
правый Option — текст читается вслух; тапнул ещё раз — замолкает.

По одному действию за ход, каждое — с разрешения:

```bash
brew install sox                            # плеер play
brew install --cask karabiner-elements      # перехват правого Option, попросит свои разрешения
mkdir -p "$HOME/.local/bin" && cp "${CLAUDE_PLUGIN_ROOT}/assets/speak.sh" "$HOME/.local/bin/speak.sh" && chmod +x "$HOME/.local/bin/speak.sh"
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/apply-karabiner.py" --rule "${CLAUDE_PLUGIN_ROOT}/assets/karabiner-rule.json"
```

Karabiner при первом запуске просит доступ к вводу в Системных настройках — это его собственный
диалог, проведи человека по нему. Правило вносится по описанию и повторный запуск дубля не делает.

Проверка: скопируй любое предложение → тап правого Option → слышно голос → тап ещё раз → тишина.

## Шаг 7. Итог

Скажи тремя короткими блоками:

1. **Что теперь есть.** Диктовка по правому Command; при желании — озвучка по правому Option.
2. **Что изменилось на диске.** Настройки Spokenly (бэкап в `~/Archive/`), ключи в Связке ключей,
   и — если ставили озвучку — `~/.local/bin/speak.sh` плюс одно правило в конфиге Karabiner.
3. **Следующий шаг маршрута** — `/search` (плагин `jadlis-search`): поиск и ресерч.

Приложение Spokenly есть и для iPhone — отдельной настройки от тебя оно не требует.
