# Тир «Голос» — что стоит за плагином

Справочная страница: из чего собран голосовой контур и почему собран именно так.
Ставит его команда `/jadlis-voice` — руками по этой странице ходить не нужно.

## Зачем

Длинный промпт руками не набирают — мысль обрывается на середине фразы.

- Проблема: чем дороже сказать, тем короче задание агенту — и тем хуже результат.
- Что делает: речь → чистый текст с пунктуацией, без хезитаций и слов-паразитов, смысл на месте.
- Почему шаг третий: всё, что дальше, — это разговор с агентом. Голос делает разговор дешёвым.

## Как выглядит

Речь проходит два облачных шага и возвращается текстом в то поле, где стоит курсор:

1. **Речь в микрофон** — нажал правый Command, говоришь, нажал ещё раз.
2. **Словарь замен** — десять пар вида «слышит → пишет» срабатывают до чистки (`beforeAI`).
3. **Распознавание** — ElevenLabs `scribe_v2` превращает звук в буквы со всеми «э-э-э».
4. **Чистка** — Anthropic `claude-sonnet-5` убирает мусор и ставит запятые; при отказе
   подхватывает резерв OpenAI `gpt-5.6-sol`, если его ключ заведён.
5. **Готовый текст в активном поле** — режим `autoInsert`, вставка без буфера обмена.

**До — как услышал STT:**

> ну вот я это, хочу чтобы ты э-э-э посмотрел на нашу папку с заметками и там, как бы, нашёл все файлы где нет заголовка, и в общем сделааал список, ну то есть просто список, ничего не меняй пока

**После — что попало в поле:**

> Хочу, чтобы ты посмотрел на нашу папку с заметками и нашёл все файлы, где нет заголовка, и сделал список. Просто список, ничего не меняй пока.

Смысл, обращение и «пока» на месте; ушли хезитации, «как бы», «в общем» и удлинение гласной.

</details>

Вторая, необязательная ветка — озвучка: скопировал текст, тапнул правый Option, слушаешь;
тапнул ещё раз — замолкает. Правило перехвата клавиши держит Karabiner-Elements, читает голосом
`speak.sh` через ElevenLabs, звук выводит `play` из пакета sox.

## Что внутри плагина

| Файл | Что это |
|---|---|
| `assets/spokenly-template.plist` | 25 настроек Spokenly с плейсхолдерами вместо ключей: режим, горячая клавиша, промпт чистки, словарь замен |
| `docs/prompt.txt` | тот же промпт корректора отдельным файлом — чтобы прочитать глазами |
| `tools/spokenly-apply.py` | подставляет ключи из Связки и вносит шаблон в живой домен настроек |
| `tools/spokenly-export.py` | обратная операция для владельца: живые настройки → шаблон без ключей |
| `assets/speak.sh` · `assets/karabiner-rule.json` | ветка озвучки: скрипт и правило правого Option |

Живой домен настроек адресуется **путём к файлу** `~/Library/Preferences/app.spokenly.plist`:
бандл-id `app.spokenly` ведёт в старый sandbox-контейнер, приложение вышло из песочницы в 08.2026.
`defaults import` по пути **дополняет** домен — микрофоны, выданные разрешения и служебные ключи
Spokenly переживают импорт.

## Как пользоваться

Горячая клавиша — единственная кнопка, которой пользуешься каждый день.

1. **Длинное задание агенту.** Курсор в поле ввода Claude Code → правый Command → говоришь весь
   контекст вслух → перечитываешь глазами → отправляешь.
2. **Мысль на ходу.** Курсор в заметке → правый Command → текст ложится сразу отредактированным.
3. **STT стабильно врёт на слове.** Добавляешь пару «слышит → пишет» в Word Replacements.
   Так словарь и растёт: своими проектами, инструментами, фамилиями.
4. **Длинный текст глазами читать лень.** Копируешь → тап правого Option → слушаешь.

Критерий, что всё работает: диктуешь два предложения с «ну» и «э-э-э» — хезитации ушли,
смысл остался.

## Границы и стоимость

Два платных аккаунта обязательны, третий по желанию; все ключи — твои собственные.

- **Оплата по факту** у всех: ElevenLabs, Anthropic, OpenAI. Подписки нет, минимальное
  пополнение нужно на каждом. Точные цены — на страницах тарифов провайдеров.
- **Ключи Spokenly лежат в его файле настроек открытым текстом.** Не пересылай этот файл,
  не клади в репозиторий и не давай агенту его читать. Это исключение из общего стандарта
  (Связка ключей macOS): своего Keychain-канала Spokenly не даёт.
- **Всё уходит в облако:** речь — в ElevenLabs, текст — в Anthropic (резерв — OpenAI).
  Без интернета маршрут не работает; чувствительное вслух не диктуй.
- **Только macOS.** Spokenly существует ещё и на iPhone, но настройка там своя и отдельная.
- **Не делает:** не переводит, не пересказывает, не сокращает больше чем на треть.
  Ошибки распознавания на именах лечатся только словарём замен.

Spokenly — стороннее бесплатное приложение с необязательной подпиской Pro; к этому плагину
его авторы отношения не имеют.
